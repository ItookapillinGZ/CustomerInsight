# 两批合成评价示例

唯一权威数据文件是 [`core/demo_data/reviews.json`](../../core/demo_data/reviews.json)，由开发者编写，版本为 `demo_workspace_v1`。数据随 `core` 包一起打入 wheel，也随源码和 Docker 镜像分发。不来自真实顾客、公共评价网站或上传历史，不包含姓名、联系方式或真实订单。本目录只保留来源说明，不维护第二份数据。

- 场景：虚构的“青岚杯具”，三个商品，两批各 30 条评价。
- 上批日期：2026-10-01 至 2026-10-07；本批：2026-10-08 至 2026-10-14。
- `review_id` 是稳定示例编号；原表每张评价工作表从第 2 行开始，两批行号独立。
- 情感、类别、优先级和方面标签由开发者预置，用于演示，不是 LLM 预测、人工金标准或模型质量成绩。
- 每个方面的 `evidence` 都是对应评价中的连续原文。报告和回放数字由这些记录计算。
- `load_demo_workspace()` 不读取用户历史、不写入数据库、不访问网络、不消耗接口。自由追问是另行明确发起的实时操作。
- 下载的工作簿包含本批、上批原始数据和来源说明，不包含情感或其他标签列；重新上传会走正常分析流程。

可体验的路径：本批问题主题 → 对应原文 → 两轮离线示例回放 → 两批对比。所有变化仅用于演示，不能推断真实业务趋势或措施因果效果。
